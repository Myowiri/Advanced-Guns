# Advanced Guns

Advanced Guns is a lightweight yet powerful combat mod that introduces responsive, physics-based firearms into Minecraft. Engineered for high performance, the mod replaces instant-hit mechanics with custom projectile entities to deliver a deeply satisfying shooting experience.


## 🎮 Controls & Reloading Mechanics

You can customize all keybinds in the Controls menu under the Weapons category.

### Default Keybinds

 • R — Reload weapon or magazine

 • Y — Check ammo / weapon 

### How to Reload

1. Loading a Magazine: Hold the Ammo in your Off-hand and the Magazine in your Main hand, then press R.

2. Loading a Gun: Hold a loaded Magazine (or a PG-7V Rocket for the RPG) in your Off-hand and the Gun in your Main hand, then press R.

## ⚙️ Configuration

All weapon stats (such as damage, bullet speed, and reload cooldowns) can be customized in the configuration file:

• Config file path: config/advancedguns.json

• Live Reload: You do not need to restart the game to apply changes! Simply run the following command in-game:

```/advanced-guns reload```
